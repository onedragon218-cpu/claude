# 상장기업 장기 재무성과 분석 시스템 — 사용 설명서

종목코드를 넣으면 과거 10년 실적, 현재 연도, 향후 2년 컨센서스로 7개 지표(매출액, 영업이익률, EPS, BPS, ROE, 부채비율, 시가총액)를 모으고 검증해서 SQLite DB에 쌓는다. 같은 종목을 다시 조회하면 **DB에 없는 값만** 수집한다.

- 별도 설치 없음: Python 3.10 이상, 표준 라이브러리만 사용
- DB: `data/analyzer.db` · 화면: `data/output/<종목코드>.html` (윈도우 설치 시 `%LOCALAPPDATA%\CorpAnalyzer\data`)

## 1. 빠른 시작

```bash
python -m analyzer analyze 213500          # 한솔제지 분석 → data/output/213500.html
python -m analyzer analyze 한솔제지         # 종목명도 됩니다(DART 키가 있으면 전체 상장사에서 찾음)
python -m analyzer analyze 213500          # 다시 실행: 외부 요청 0건, 기존 값 재사용
python -m analyzer analyze 005930 --base-year 2027   # 다른 종목, 기준 연도 변경
python -m analyzer serve                   # http://localhost:8765 에서 화면 A~F 사용
```

기타 명령

| 명령 | 하는 일 |
|---|---|
| `python -m analyzer status 213500` | 상태별 값 개수, 컨센서스 스냅숏 수, 변경 이력 수 |
| `python -m analyzer report 213500` | 수집 없이 화면만 다시 만들기 |
| `python -m analyzer import-consensus 213500 파일.csv` | 컨센서스를 CSV로 넣기(시점별 저장) |
| `python -m analyzer reverify 213500 --year 2024` | 사용자 재검증 요청: 해당 연도 값을 STALE로 바꾸고 다음 실행 때 다시 받아 비교 |
| `python -m analyzer update-all` | DB의 모든 기업 갱신(자동 실행용) |
| `python -m unittest discover -s analyzer/tests -t .` | 시험 10개 |

화면 A: 종목코드·종목명 검색(입력하면 후보가 뜸), DB 기업 목록을 누르면 그 기업 화면으로 이동합니다.

화면 C(통합 그래프): **표준화 비교**, **원데이터 중첩**(실제 단위, 억원·원은 왼쪽 축, %는 오른쪽 축), **지표별 원데이터**(지표 1개 그래프와 연도별 표)를 탭으로 오갈 수 있습니다. 마지막으로 고른 탭은 브라우저에 기억됩니다.

2. 제외(규칙은 `analyzer/screener.py`): 우선주·기타 종류주(종목코드 끝자리 ≠ 0, 이름이 '우'로 끝남) 114, 스팩 70, 리츠(이름이 '리츠'로 끝남) 23, 인프라펀드(맥쿼리인프라·KB발해인프라) 2 → 2,667종목 확인 대상. '메리츠금융지주'·'바이오인프라' 같은 일반 기업은 빠지지 않게 했습니다.

4. 결과는 데이터 폴더 `consensus_scan.json`. 처음에는 20~30분, 이후에는 7일이 지난 종목만 다시 확인합니다(중간에 끊겨도 이어서).
4-1. 상장 유지 위험(`analyzer/risk.py`, DART 키 필요): 컨센서스가 있는 종목마다 DART 거래소 공시(최근 12개월)와 최근 보고서 주요계정(자본금·자본총계)을 확인합니다. 종목당 요청 2~5건입니다.
   - **제외**: 관리종목, 투자주의환기종목, 상장폐지·상장적격성 실질심사, 거래정지(가장 최근 정지 공시 뒤 해제 없음), 감사의견 비적정(거절·부적정·한정), 회생·파산, 자본잠식률 50% 이상 또는 완전잠식(한국거래소 관리종목 기준)
   - **주의**: 관리종목 지정 우려, 부분 자본잠식(0~50%)
   - 해제·상장유지 공시가 뒤에 있으면 풀린 것으로 봅니다. 화면 기본값은 '제외' 종목을 빼고 보여 주며, '주의까지 빼기'·'함께 보기'·'위험·주의만 보기'를 고를 수 있습니다. DART 키가 없으면 '미확인'으로 남고 빼지 않습니다.
   - 한국거래소 관리종목·투자유의 목록 화면은 로그인이 필요해 쓰지 않습니다.
5. 화면에서 시장·이름·업종·최소 추정기관 수로 거르고 열 제목으로 정렬, 체크한 종목을 기본 목록에 추가(데이터 폴더 `universe_user.tsv`), 개별 수집, CSV 저장.

## 2. 자동 수집(GitHub Actions)

이 개발 환경에서는 DART·FnGuide·네이버 접속이 막혀 있어서, **수집 코드는 GitHub 서버에서 자동으로 실행**되도록 `.github/workflows/collect.yml`을 넣었다.

- 매주 월·목 07:13(한국시간)에 DB의 모든 기업을 갱신하고, 바뀐 DB와 화면을 저장소에 커밋한다.
- Actions 화면의 "Run workflow"로 언제든 수동 실행할 수 있다(종목코드, 기준 연도 입력 가능).
- 처음 한 번은 아래 설정이 필요하다.

**해야 할 일(순서대로)**
1. DART 인증키 발급: https://opendart.fss.or.kr → 인증키 신청/관리 → 인증키 신청(무료, 보통 당일 발급)
2. GitHub 저장소 → Settings → Secrets and variables → Actions → New repository secret
   - Name: `DART_API_KEY`
   - Secret: 발급받은 40자리 키
3. 예약 실행은 **기본 브랜치에 workflow 파일이 있어야** 동작한다. 이 브랜치를 기본 브랜치에 병합하거나, 병합 전에는 Actions 화면에서 이 브랜치를 골라 수동 실행한다.
4. 첫 실행 뒤 Actions 기록과 `data/output/last_update.json`에서 다음 두 가지를 확인한다. FnGuide 컨센서스 표 해석과 네이버 시세 해석은 이 환경에서 실제 페이지로 시험하지 못했다.

## 4. 저장 규칙(재수집 방지)

- `facts`: 분석에 쓰는 대표값이다. 값이 바뀌면 **새 버전**을 만들고, 이전 값은 `is_current=0`으로 남긴다(변경 이력).
- `observations`: 출처와 보고서별 원본 관측값이다. 후속 보고서의 전기 열(재작성 값)도 따로 보관한다.
- `consensus`: 수집 기준일마다 새로 쌓는다. 같은 시점 자료가 다시 오면 무시하고, 덮어쓰지 않는다.
- `fetch_log`: 요청 기록이다. 확인했지만 자료가 없던 항목은 7일 동안 다시 묻지 않는다.
- 갱신 조건: 빈 값, 새 분기·사업보고서, 정정 공시(그 연도만 STALE로 바꾼 뒤 재수집), 컨센서스(7일), 기준일 주가(1일), 사용자 재검증 요청.
- 대표값 선택: 그 연도 자신의 보고서를 먼저 쓰고, 정정 공시가 있으면 최신 접수번호를 쓴다. 그 보고서가 없으면 그 연도를 처음 담은 후속 보고서의 값을 쓴다.

검증 상태

| 상태 | 뜻 |
|---|---|
| VERIFIED | DART 원천 계정: 자산=부채+자본이 맞고 다른 출처와 어긋나지 않음. 계산 지표: 입력값이 모두 VERIFIED |
| UNVERIFIED | 검증이 끝나지 않음(예: 공식 주식 수 없이 역산한 BPS·시가총액) |
| CONFLICT | 출처 간 불일치, 또는 회계 등식 불일치 |
| CORRECTED | 정정 공시로 값이 바뀜 |
| STALE | 정정 공시 확인 또는 재검증 요청으로 다시 받아야 함 |
| MISSING | 자료 미확보 |

## 5. 지표 계산식

| 지표 | 계산 |
|---|---|
| 매출액(억원) | 연결 매출액 ÷ 1억 |
| 영업이익률(%) | 영업이익 ÷ 매출액 × 100 |
| EPS(원) | 연결 손익계산서의 기본주당이익(보통주) 원본 |
| BPS(원) | 지배주주 자본 ÷ (보통주+우선주−자기주식). 공식 주식 수가 없으면 역산 주식수(지배순이익÷EPS)를 쓰고 UNVERIFIED로 표시 |
| ROE(%) | 지배주주 순이익 ÷ (전년말+당년말 지배주주 자본)/2 × 100 |
| 부채비율(%) | 부채총계 ÷ 자본총계 × 100 |
| 시가총액(억원) | 연말 보통주 종가 × 보통주 발행주식수(우선주 제외). 공식 주식 수가 없으면 역산 주식수 사용(주의 표시) |

- 현재 연도: 부채비율·BPS·시가총액은 최신 실제값(반기말, 기준일)을 쓴다. 매출·EPS·ROE는 컨센서스를 쓰고, 부분 실적(H1 등)은 연간 값처럼 그리지 않고 표와 툴팁에만 보여준다.
- 통합 그래프 표준화: 모든 값이 양수이고 기준값이 최댓값의 5% 이상이면 `첫해=100` 지수로 그린다. 아니면 기간 최솟값을 0, 최댓값을 100으로 놓고 정규화한다. 지표별 방식은 화면 C에 표시한다.

## 5-1. 가치평가(화면 G)

| 탭 | 내용 |
|---|---|
| 전체 중첩(기본) | 주가·S-RIM·DCF·PER·PBR·PSR 가치·종합(원, 왼쪽 축)과 ROIC·WACC·Ke(%, 오른쪽 축)를 한 그래프에 겹치고 ROIC−WACC 구간을 색칠 |
| 주가 vs 주당가치 | 연말 주가(현재 연도는 기준일 주가) 위에 S-RIM, DCF(FCFF), PER·PBR·PSR 가치, 종합(중앙값)을 겹쳐 그림. 값 차이가 8배를 넘으면 처음부터 로그 축 |
| ROIC vs WACC | 두 선을 겹치고 사이를 색칠(ROIC>WACC 초록 = 가치 창출, 반대 빨강 = 가치 훼손). 자기자본비용 Ke를 점선으로 함께 표시 |
| 계산 근거 표 | 연도별 Rf, Ke, Kd, 세율, WACC, ROIC, NOPAT, 투하자본, FCFF, 차입금, 현금, 실제·적정 배수 |
| 가정 | 계산식과 가정값(`analyzer/assumptions.json`) |

계산식(모두 지배주주 기준)

| 항목 | 계산 |
|---|---|
| Ke | 그해 국고채 10년 연평균 + 베타(1.0) × 시장위험프리미엄(5.5%) |
| Kd | 이자지급 ÷ 평균 차입금. 1% 미만·15% 초과면 Rf + 1.5%p |
| 세율 | 법인세 ÷ 세전이익. 0~50% 밖이거나 세전이익 ≤ 0이면 25% |
| WACC | 시가총액 비중 × Ke + 차입금 비중 × Kd × (1−세율) |
| ROIC | 영업이익 × (1−세율) ÷ 평균(자본총계 + 차입금·사채·리스부채 − 현금·단기금융상품) |
| S-RIM | B + B×(ROE−Ke)×0.9 ÷ (1+Ke−0.9). ROE는 최근 3년 3:2:1 가중 |
| DCF(FCFF) | FCFF = 영업현금흐름 − 유형·무형자산 취득 + 영업활동 이자지급×(1−세율). 3년 3:2:1 가중 → ×(1+g)/(WACC−g) − 순차입금 → 지배지분 비율 |
| PER·PBR·PSR 가치 | 그 연도까지 자기 배수의 중앙값(최소 3년) × EPS·BPS·주당매출. 적자 해는 PER 제외 |
| 종합 | 계산된 방법이 3개 이상일 때만 중앙값 |
| 현재 연도 | 재무상태는 최근 분기·반기말, 흐름은 최근 12개월(전년 연간 + 올해 누적 − 전년 같은 기간), 주가는 기준일 |
| 미래 연도 | 컨센서스(EPS·BPS·ROE·매출)가 있을 때만. DCF 제외 |

DCF(이익 기준): 가중 세후영업이익(NOPAT) ÷ WACC − 순차입금 → 지배지분. 콘텐츠 제작비처럼 투자가 영업현금흐름에 잡혀 현금흐름 기준 DCF를 계산할 수 없는 회사에도 실제 영업이익으로 계산합니다. 새 투자가 자본비용만큼만 번다고 보는 보수적 가정이며, 종합(중앙값)에는 넣지 않습니다.

차입금 판정: 재무상태표에 차입금·사채·리스부채 줄이 없을 때, 이자지급 ÷ (무위험수익률+1.5%p)가 총자산의 5% 미만이면 원본대로 차입금 0으로 봅니다(예: 스튜디오드래곤 2019~2021). 5% 이상이면 차입금이 다른 금융부채 줄에 묶인 것으로 보고 값을 만들지 않고 빈칸으로 둡니다(예: 메디톡스 2017~2022).

빈 연도 표시: 화면 위 '빈 연도 점선으로 잇기'(기본 켬)는 앞뒤 실제 값을 가는 회색 점선으로만 잇습니다. 빈 연도에 값을 넣거나 색칠하지 않으며, 툴팁과 '연도별 계산 메모'에 빈칸 이유가 나옵니다. 끄면 처음 지시서(6-2)대로 끊어서 보여 줍니다.

빈칸 규칙: 가중 FCFF ≤ 0, DCF 지분가치 ≤ 0, 차입금 줄이 재무상태표 본문에 따로 없을 때(예: 메디톡스 2017~2022, 금융부채에 포함), 적정 배수 관측이 3년 미만인 경우에는 값을 내지 않고 이유를 '계산 메모'에 적습니다. WACC − g < 3%p이면 DCF가 크게 부풀 수 있다는 주의를 붙입니다.

### 순차입금 ÷ EBITDA 판정

| 구간 | 순차입금 ÷ EBITDA | 순차입금비율(표시용) |
|---|---|---|
| 안전 | 순현금(0 미만) 또는 1배 미만 | 50% 이하 |
| 보통 | 1~3배 | 50~100% |
| 주의 | 3~4배 | 100% 초과 |
| 위험 | 4배 이상, 또는 EBITDA ≤ 0('EBITDA 적자, 계산 불가') | – |

- 이자보상배율 1 미만인 연도는 '주의'를 '위험'으로 올립니다. 순차입금이 있는 상태에서 배수가 2년 이상 연속 오르면 '악화 추세'(▲)로 표시합니다(순현금 축소는 제외).
- 감가상각비 출처 순서: ① DART 재무제표 본문(현금흐름표 조정 항목) ② DART XBRL 원본 주석(`collectors/dart_xbrl.py`, 빠진 연도만 받아 데이터 폴더 `raw/<종목코드>/xbrl_<접수번호>.zip`에 보관) ③ WiseReport 최근 실적 EBITDA(교차 확인값, 최근 1개 연도만). 모두 없으면 '미확인'으로 비워 둡니다.

- 올해는 TTM(전년 연간 + 올해 누적 − 전년 같은 기간)으로 계산하고, 안 되면 '반기 기준, 비교 주의'로 표시하고 판정·알림에서 뺍니다.
- 무형자산상각비가 영업이익보다 큰 해(콘텐츠·제약 등)는 EBITDA가 커 보여 배수가 낮게 나올 수 있다는 주의 문구를 붙입니다.
- 가장 최근 판정 연도가 주의·위험이면 화면 H 위에 배지(마우스를 올리면 배수·기준·연도·사유)를 띄웁니다.

## 5-6. 좋은 기업 6조건(화면 M)

원본: DOCA OS p236(사용자 기준) + 정정 F-61. 리서치 참고자료이며 투자자문이 아님 · 주가 예측이 아님. **표시 칸이며 매수 조건이 아니다.**
판정 기호는 ✓ · △ · ✗ · 조사 · 판정 못 함(이유)만 쓴다. 점수 = ✓로 시작하는 칸 수(✓(컨센 기준) 포함).
컨센서스는 DB 원래 값을 쓰고 이 앱의 보정계수는 쓰지 않는다(엔진 규칙: 고정 ×0.83, ⑥에만 적용).
`last` = 마지막 실적 연도, 최근 3년 = last−2…last, 컨센 연도 = 올해·+1·+2.

- ① pk = 과거 실적 매출 최고(DB의 모든 실적 연도). ✓ = 매출[last] ≥ pk, 또는 컨센 중 pk를 넘는 해가 +2년 안에 있고 컨센[+2] ≥ 컨센[+1]×0.97. 컨센으로만 통과하면 '원천 n곳'을 붙인다.
- ② 이익률 m = 영업이익 ÷ 매출. ✓ = 컨센 이익률 중 하나가 과거 정점 초과, 또는 m[last] > m[last−2].
- ③ ROE 추정(해석): eq = 자본총계[last]; 해마다 roe = 컨센 순이익 ÷ (eq + 순이익/2), eq += 순이익×0.75. ✓ = 추정이 과거 정점 초과, 또는 r3[-1] > r3[0] 이고 r3[-1] ≥ r3[-2]. △ = r3[-1] > r3[0] 이지만 마지막 해 꺾임. 그 외 ✗.
- ④ ✓ = 부채비율[last] ≤ 100% 또는 3년 전보다 낮음. 예외(성장 위한 증가)는 사람 메모(`four_note`)로만 붙이고 판정은 바꾸지 않는다.
- ⑤ 사람이 적는 칸. 화면에서 판정·근거를 저장 → `데이터폴더/good6_manual.json` ({코드: {five: [기호, 근거], four_note, updated}}). 코드가 자동으로 채우지 않는다.
- ⑥ 요구 영업이익 = (지금 시가총액 + 최근 순차입금) ÷ 7.8 (7.8 = 10배 × (1−세율 22%)). ✓(컨센 기준) = 요구 < 컨센 영업이익[+1]×0.83, 아니면 ✗. 추정기관 수[+1] ≤ 1 이면 '판정 못 함(원천 대기)', 비어 있으면 판정하고 '원천 수 미확인'.
  순차입금 = 가장 최근 시점(반기·3분기가 있으면 그것) 차입금 − 현금 = 화면 H와 같은 값.
- 선택(엔진 다리): 환경변수 `DOCA_ENGINE`가 있으면 `data\판\전황판_실전_*.csv` 최신 파일의 `보수중심(원)`으로 '주가 ÷ 보수중심'을 붙인다.

## 5-8. 가치 5방법(화면 O)

리서치 참고자료이며 투자자문이 아님 · 주가 예측이 아님. 계산: `analyzer/value5.py`(화면 JS와 같은 식, 시험으로 일치 확인).
- 공통: 주식수 = 발행주식(보통+우선) − 자사주. 순차입금 = 연결 차입 계정 전부 + 리스부채 − 현금·단기금융(리스는 따로도 표시). 주주가치는 지배주주 몫. 세율 22%, g = 0.
  컨센서스 이익 × 0.83, 3개월 사이 5% 넘게 깎였으면 × 0.73(영업이익은 영업이익 수정률, 순이익은 EPS 수정률). Ke = 그해 국고채 10년 + 5%(전망 연도는 최신 금리). WACC 기본값 = 화면 G의 연도별 WACC(화면에서 한 숫자로 덮어쓰기).
  전망 연도: 자본 = 전년 자본 + 보정 순이익 − 배당(마지막 실적 배당 유지), 설비투자 = 감가상각(마지막 실적값), 운전자본 증가 0, 주식수·비지배지분 = 마지막 실적값, 순차입금 = 최근 시점 값.
- ① DCF: FCFF = 영업이익×0.78 + 감가상각 − 설비투자(유형+무형) − 운전자본(매출채권+재고−매입채무) 증가. 정상화 = 최근 5개년 평균(3년 이상일 때만, 'n년 평균' 표시). 주당 = (정상화 FCFF ÷ WACC − 순차입금 − 비지배) ÷ 주식수.
- ② RIM: [지배자본 + (ROE − Ke) × 지배자본 × ω ÷ (1 + Ke − ω)] ÷ 주식수, ω = 0.6(참고선 ω = 1). ROE = 지배순이익 ÷ 평균 지배자본(전망은 보정 순이익 기준).
- ③ 자산가치(실적 연도만): [현금·단기금융 100% + 매출채권 85% + 재고 60% + 토지 100% + 건물·설비 30% − 부채총계 − 비지배] ÷ 주식수, 기타 0%. 토지·건물·설비는 XBRL 유형자산 주석에서만 읽고, 없으면 빈칸.
- ④ 스트레스: 불황 영업이익 = 올해 기준 과거 20년 영업이익 중 하위 20% 값(자료가 있는 범위에서 ceil(n×0.2)번째로 낮은 값). 주당 = (불황 영업이익 × 0.78 ÷ WACC − 순차입금 − 비지배) ÷ 주식수.
- ⑤ 재무위험: 부족분 = 3 × 이자 + 1·2·3년차 만기 − 3 × 정상화 FCFF(0 미만이면 0). 주당 = ④ × 주식수 ÷ (주식수 + 부족분 ÷ 현재가). 1년차 = 재무상태표 유동 차입, 2·3년차 = XBRL 만기 주석(없으면 빈칸). 이자 = XBRL 이자비용, 없으면 현금흐름표 이자 지급.
- 음수는 0으로 표시하고 '주주 몫 없음'을 붙인다. 추가 계정은 저장된 DART 재무제표 원본(seed·data/raw)을 다시 읽어 얻고, 최근 사업보고서 3개의 XBRL 원본을 받아 둔다(종목당 최대 3건, 실패 시 7일 뒤 재시도).

## 5-9. 우상향 저평가(화면 P)

리서치 참고자료이며 투자자문이 아님 · 주가 예측이 아님. 계산: `analyzer/upvalue.py`(화면 JS와 같은 식).
- 대상: DB에 있는 기업. 1단계 우상향 = 작년(DART 실적) < 올해 < 내년 < 내후년(컨센서스 원래 값)을 고른 지표(영업이익률·ROE·매출액·EPS) 모두 만족.
  최소 증가폭(선택): 매출·EPS는 %, 영업이익률·ROE는 %p. 작년이 적자였다가 오른 경우도 우상향(턴어라운드, 그 구간은 % 문턱 제외). 고른 지표의 컨센서스가 하나라도 없으면 제외.
- 2단계 가격: 적정가 = ROE(%) × 1/10 × 0.83(보정, 기본 켬) × BPS(그해 컨센서스) > 현재 주가. 1차 = 내후년, 2차 = 내년, 3차 = 올해 기준.
  화면 위 분류 버튼(1차·2차·3차·우상향 통과 전체·전체)으로 거른다. 분류는 서로 독립(한 기업이 여러 분류에 들 수 있음).
  표는 현재가 옆에 1·2·3차 적정가(✓ = 현재가보다 높음)와 현재가 대비 %(안전 여유), 해당 분류를 보이고, 지표 값은 그 오른쪽에 둔다.

## 7. 앱 공통 계산 기준(2026-11-13 통일, `analyzer/standards.py`)

같은 이름이면 같은 식. 모든 화면(C·G·H·J·M·N·O·P)이 아래 한 곳의 재료를 쓴다.

| 재료 | 기준 | 근거 |
|---|---|---|
| 순차입금 | 차입 계정 전부 + 리스부채 − 현금·단기금융(본문에 없으면 XBRL 주석) | 다모다란: 부채에 리스 포함 |
| 지배주주 몫 | 기업가치 − 순차입금 − 비지배지분(장부가) | 다모다란 |
| 주식수 | 발행주식(보통+우선) − 자사주(DART). 없으면 지배순이익 ÷ EPS 역산(미검증 표시) | 유통주식수 |
| 세율 | 법정 한계세율(지방소득세 포함). 구간 = 최근 5년 흑자 세전이익 중앙값. 2025년까지 9·19·21·24%, 2026년부터 10·20·22·25% × 1.1 | 다모다란: 영구 가치·부채 절세에는 한계세율 |
| Ke | 국고채 10년 + β(1.0) × ERP 5% | CAPM, 다모다란 2026-01 한국 ERP 4.87% |
| 영구성장률 g | 0 | 보수적 가정 |
| 컨센서스 보정 | 영업이익·EPS·순이익·ROE ×0.83, 그 해 3개월 사이 5% 넘게 하향이면 ×0.73, 매출 보정 안 함 | 사용자 규칙(2025년 실측 연초 영업이익 0.85·EPS 0.78) |

방법
- DCF(화면 C·G·O 같은 식): FCFF = 영업현금흐름 + 영업 이자지급 × (1−t) − 설비투자(유형+무형). 정상화 = 최근 5년 평균(3년 이상). 전망 연도 FCFF = 보정 영업이익 × (1−t). 주당 = (정상화 FCFF × (1+g) ÷ (WACC − g) − 순차입금 − 비지배지분) ÷ 주식수. 음수면 0(주주 몫 없음)이며 종합 중앙값에서 뺀다.
- NOPAT÷WACC(무성장): 영업이익 × (1−t)의 5년 평균 ÷ WACC − 순차입금 − 비지배지분. (예전 이름 'DCF(이익 기준)')
- S-RIM(ω 0.9, 화면 C·G) 과 RIM(ω 0.6, 화면 O)은 이름이 다른 별개 방법. 둘 다 같은 Ke·지배자본·주식수를 쓴다. 전망 연도 자본 = 전년 자본 + 보정 순이익 − 배당(마지막 실적 유지).
- 화면 M ⑥ 요구 영업이익 = (시총 + 순차입금) ÷ (10 × (1 − t)), 화면 P 적정가 = ROE × BPS ÷ 10 × 보정.
- 올해 열: 화면 G·C는 최근 12개월 실적(분기·반기 보고서가 있을 때), 화면 O는 올해 컨센서스라 값이 다를 수 있다.

- **화면 P**: 고른 지표의 작년 실적·컨센서스가 비면 '자료 부족' 묶음으로 따로 보여 준다(예전에는 제외). 있는 값만으로 이미 우상향이 깨졌으면 '우상향 아님'.

## 8. 적정 PER · 연도별 적정 주가(화면 Q, 2026-11-14, `analyzer/fairper.py`)
- 틀은 화면 P와 같다: 1단계 우상향(P와 같은 지표·문턱, 모두 끄면 거르지 않음) → 2단계 가격. 1차 = 내후년, 2차 = 내년, 3차 = 올해 오늘가치 > 지금 주가(서로 독립).
- ROE 이월: 시작 지배자본 E₀ = 작년 사업보고서 acc_eq_owner(없으면 최근 FY). 해마다 순이익 = 컨센 순이익 × k, 기말 자본 = 기초 + 순이익 × (1 − d), ROE = 순이익 ÷ 평균 자본. d = 최근 3년 배당금 지급 합 ÷ 지배순이익 합(0~1, 없거나 합 ≤ 0이면 25% 가정). 자사주 소각 미반영.
- 적정 PER = (1 − g ÷ ROE) ÷ (Ke − g) (고든 정당화 PER). 적자·순이익 컨센 없음, Ke − g < 2%p, ROE ≤ g는 '판정 못 함'. g 기본 3%(상한 4%, 화면에서 2·3·4%).
- 적정 주가 = 적정 PER × EPS(컨센 × k), 오늘가치 = 적정 주가 ÷ (1 + Ke)^t, t = 그해 1월 1일까지 남은 해(지난 시점은 0).
- 같은 재료: k = standards.factors(×0.83, 급하향 ×0.73, 토글로 앱 실측 보정계수), Ke = 국고채 10년(ECOS 자동 포함) + β × ERP(화면 G·O와 같음, 토글로 10% 고정).
- 판정(표시 전용): 가치 경로 = 내후년 ÷ 올해 오늘가치(±10%), 가격 위치 = 지금 주가 ÷ 올해 오늘가치, 시장 PER = 주가 ÷ 컨센 EPS(비교 열). 꼬리표: 원천 1곳(분류 제외)·원천 수 미확인·정점 넘음·깊은 보정·금융.
- 화면 JS(qCompute)와 Python(compute)은 같은 식이며, 지금 기업 결과를 payload의 check로 맞춰 본다.
