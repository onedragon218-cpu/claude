# 본질가치 13년 추이 (LG전자 · 한솔제지 · 메디톡스)

기준일: 2026-11-03 · 대시보드: https://claude.ai/artifact/9xwrxpt4k3mJ2cfzUfomF3 (비공개, 공유 전에는 본인만 열람)

## 무엇을 했나
- 2016~2025년: 그해 사업보고서 숫자와 그해 국고채 10년 금리만으로 그해 말 기준 본질가치를 다시 계산.
- 2026년: 최근 12개월(2025년 + 2026년 상반기 − 2025년 상반기), 자본은 2026-06-30. 3분기 보고서는 기준일 현재 미공시.
- 2027~2029년: 2026년 값에서 출발한 보수·기본·낙관 시나리오.
- 방법 4가지(S-RIM, DCF, DDM, 상대가치)와 그 중앙값(종합).

## 파일
| 경로 | 내용 |
|---|---|
| `raw/<회사>_<연도>.json` | DART 전체 재무제표(연결)에서 뽑은 핵심 계정. `source_rcept_no`가 공시 접수번호 |
| `raw/<회사>_2026_H1.json` | 2026년 반기보고서 값 |
| `inputs.json` | 가정값, 금리(ECOS), 배당 총액(DART 배당 공시), 연말 수정주가(KIS), 주식 수 |
| `scripts/extract.py` | DART 응답에서 계정 추출 |
| `scripts/model.py` | 4가지 방법 계산. `python3 scripts/model.py` |
| `output/results.csv` | 전체 결과표(엑셀에서 열림) |
| `output/valuation.csv`, `output/assumptions.csv` | 대시보드에 올린 자료 |
| `output/index.html` | 대시보드 화면 원본 |

## 핵심 가정 (바꾸면 결과가 바뀜)
- 요구수익률 = 국고채 10년 + 5.5%p (세 회사 동일)
- 영구성장률 1.5%, S-RIM 초과이익 지속계수 0.9
- 상대가치 기준 PER 10배, PBR 1.0배 (업종 차이 미반영)
- 주식 수는 현재 기준으로 고정하고 과거 주가는 수정주가 사용
- LG전자 우선주는 보통주와 같게 취급

## 알려진 한계
- DCF는 차입금 증감을 넣지 않은 간이 FCFE라서 투자가 많은 해에는 음수가 되어 계산하지 못함.
- DDM은 배당을 적게 주는 회사(LG전자, 메디톡스)에서 값이 매우 낮게 나옴.
- 메디톡스 2021년 이익에는 소송 합의금 등 일회성 이익이 섞여 있을 수 있음(미확인).
- 메디톡스는 2026년 상반기 전환상환우선주 상환(약 767억 원)으로 자본이 줄었음.
