# fintrack — 기업 장기 재무 추이 (Windows 11 로컬 실행)

종목을 입력하면 과거 10년 확정 실적(DART), 올해 분기·반기 실적, 향후 2년 컨센서스(FnGuide)를 모읍니다.
7개 지표(매출액·영업이익률·EPS·BPS·ROE·부채비율·시가총액)를 **통합 그래프 1개 + 개별 그래프 7개**로 보여 줍니다.
분석한 종목은 탭으로 남습니다. 모든 자료는 사용자가 고른 **작업 폴더** 안의 DB에 쌓이고, 한 번 검증한 값은 다시 받지 않습니다.

## 처음 설치 (한 번만)

1. Python 3.10 이상 설치: https://www.python.org/downloads/
   - 설치 첫 화면에서 **Add python.exe to PATH** 를 체크합니다.
2. 이 `fin_tracker` 폴더를 PC의 원하는 곳에 둡니다(예: `D:\fintrack_app`).
3. `setup_windows.bat` 더블클릭 → 라이브러리를 설치합니다(2~3분).
4. `run_fintrack.bat` 더블클릭 → 처음 한 번 **작업 폴더 선택 창**이 뜹니다(예: `D:\투자\fintrack_data`).
5. 브라우저에 화면이 열리면 오른쪽 위 **설정** → **DART 인증키** 입력 → **저장**.

## 매일 쓰는 법

| 하고 싶은 일 | 방법 |
|---|---|
| 프로그램 열기 | `run_fintrack.bat` 더블클릭(검은 창은 켜 둔 채로 사용, 닫으면 종료) |
| 새 종목 분석 | 위 입력란에 종목코드나 회사명 입력 → 목록에서 선택 또는 **분석** |
| 분석했던 종목 보기 | 위쪽 탭 클릭(조회 없이 DB에서 바로 열림) |
| 최신 정보 반영 | 종목 화면의 **최신 정보로 갱신** |
| 인증키 없이 둘러보기 | 첫 화면의 **예시 불러오기(한솔제지)** |
| 공유용 파일 | 작업 폴더 `output\<종목코드>.html` (인터넷 없이 열림) |

**갱신이 하는 일:** 사업보고서 정정 공시 확인(있으면 그 연도를 새 버전으로 다시 받음), 올해 새 분기·반기 보고서, FnGuide 컨센서스, 오늘 시세를 조회합니다.
이미 검증한 과거 실적은 다시 받지 않습니다. 컨센서스는 갱신한 날짜마다 따로 쌓여 전망 변화를 추적할 수 있습니다.

## 인증키 보관
- 키는 **Windows 자격 증명 관리자**에만 저장합니다(제어판 → 자격 증명 관리자 → Windows 자격 증명 → `fintrack`).
- 파일, 화면, 로그, 작업 폴더 어디에도 키를 쓰지 않습니다. 설정 창은 '등록됨' 여부만 보여 줍니다.
- 명령으로 넣으려면(입력이 화면에 안 보임): `.venv\Scripts\python -m fintrack set-key`

## 보안
- 화면 서버는 `127.0.0.1`(이 PC)에만 열립니다. 다른 PC나 인터넷에서는 접속할 수 없습니다.
- 실행할 때마다 새 접속 토큰을 만들고, 모든 요청에서 토큰과 주소를 확인합니다. 다른 웹사이트가 이 서버를 몰래 호출하지 못하게 하기 위해서입니다.

## 작업 폴더 구조
```
<작업 폴더>
  fintrack.sqlite      DB (실적·전망·시세 원값, 버전, 변경 이력, 조회 기록, 검증 결과)
  raw\dart\            DART 응답 원본(gzip)
  raw\fnguide\         FnGuide 화면 원본(날짜별)
  raw\krx\             연말 시가총액 원본
  manual\              손으로 넣는 보조 자료(선택)
  output\              공유용 화면 파일
```
이 폴더만 백업하면 됩니다. 다른 폴더로 바꾸려면 설정 → **다른 폴더 고르기**.

## 자료 출처와 검증

| 지표 | 출처 | 검증 |
|---|---|---|
| 과거 10년 실적 | DART 사업보고서(연결, 없으면 별도) | 접수번호, 자본 항등식, EPS×주식수=순이익, FnGuide 실적 열과 대조 |
| 주식 수 | DART 주식총수 현황(보통주·우선주·자기주식) | BPS는 자기주식을 뺀 주식수로 계산 |
| 올해 실적 | DART 최근 분기·반기 보고서(누적) | 접수번호, 자본 항등식 |
| 연말 시가총액 | 한국거래소(pykrx) → 실패 시 네이버 차트 종가×DART 주식수 | 거래소 값은 종가×상장주식수와 대조, 계산값은 '미검증' |
| 향후 전망 | FnGuide Financial Highlight(연결·연간, E 열) | 같은 화면의 실적 열이 DART와 맞아야 '검증 완료', 최근 BPS 대비 현실성, 추정 기관 수 |
| 교차검증 | WiseReport(올해 EPS·BPS 전망) | FnGuide 전망과 비교 |

상태 표시: 검증 완료 · 미검증 · 불일치 · 정정됨 · 미확보. 빈칸은 추정해서 채우지 않습니다.

## 문제가 생기면

| 증상 | 할 일 |
|---|---|
| `setup_windows.bat`에서 Python을 못 찾음 | Python을 다시 설치하면서 **Add python.exe to PATH** 체크 |
| 검색 결과가 비어 있음 | 설정에서 DART 인증키 등록 여부 확인 |
| 'FnGuide 응답 302' 또는 '표를 찾지 못함' | 작업 폴더 `raw\fnguide\`의 오늘 파일을 보내 주시면 해석기를 맞춥니다 |
| 'pykrx 실패' | 한국거래소 접속 방식이 바뀐 경우입니다. 네이버 종가로 대신 계산되고 '미검증'으로 표시됩니다 |
| 포트 8765 사용 중 | `.venv\Scripts\python -m fintrack serve --port 8790` |

## 명령줄(선택)
```
.venv\Scripts\python -m fintrack run 213500 --refresh   # 화면 없이 수집·갱신
.venv\Scripts\python -m fintrack where                   # 작업 폴더·키 저장 위치
.venv\Scripts\python -m unittest discover -s tests       # 시험
```

## 알려진 한계
- FnGuide·한국거래소·네이버 수집은 개발 환경에서 접속이 막혀 **가상 시험 화면으로만 확인**했습니다. 첫 실행 결과를 확인해야 합니다.
- FnGuide 이용약관은 자동 수집을 제한할 수 있습니다. 이 프로그램은 갱신 버튼을 눌렀을 때만, 종목당 한 장, 하루 한 번 이내로 조회합니다(같은 날 다시 누르면 보관 원본 사용).
- 추정 기관이 없는 중소형주는 전망이 비어 있습니다.
