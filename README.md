# 상장기업 장기 재무성과·가치평가 시스템

종목코드를 넣으면 DART 공시로 과거 10년 실적을 모읍니다. 이를 검증해 DB에 쌓고, 7개 재무지표와 가치평가 결과를 그래프로 보여줍니다. 가치평가는 S-RIM, DCF, ROIC·WACC, PER·PBR·PSR 상대가치입니다.

- **윈도우11 설치·업데이트**: [windows/README.md](windows/README.md)
- **사용 설명서(계산식·데이터 규칙)**: [analyzer/README.md](analyzer/README.md)
- **ZIP 받기**: https://github.com/onedragon218-cpu/claude/archive/refs/heads/claude/zen-lamport-1jplcv.zip

| 폴더 | 내용 |
|---|---|
| `analyzer/` | 프로그램(수집·검증·계산·화면) |
| `windows/` | 윈도우 설치·실행·제거 스크립트 |
| `data/` | 초기 DB와 결과 화면(한솔제지, 메디톡스) |
| `valuation/` | 이전 단계의 본질가치 계산 자료(참고용) |
